# Computer Use Workbench v3.2.0

Released 2026-08-16.

## Highlights

- Live **Desktop** dropdown: sandbox Docker (default) or native host.
  Native host drives this machine. Confirm-mutating turns on when you
  pick it. Use a test account.
- Live **Session log** under the viewport, with Copy logs.
- noVNC has no VNC password. Provider web search is `mcp_fetch`, not
  vendor `web_search`.

Review `CHANGELOG.md` and `USAGE.md` before upgrading an existing
deployment.
