# Computer Use Workbench v3.1.1

Released 2026-08-16.

## Highlights

- Live Mission control is in the left CONTROL sidebar. The main pane is
  the sandbox viewport.
- Session cost at `/cost` estimates USD from recorded EXECUTION tokens
  and published list rates.
- A process-level `GOOGLE_API_KEY` is not overwritten by `.env`.

Review `CHANGELOG.md` and `USAGE.md` before upgrading an existing
deployment.
